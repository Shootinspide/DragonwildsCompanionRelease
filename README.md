# Dragonwilds Companion Releases

This repository is the official download and update channel for the
**Dragonwilds Companion** Windows desktop and Android apps.

The companion provides live skill XP tracking, XP-per-minute estimates, an
interactive resource map, player-position tracking, custom pins, route
planning, and a quest and achievement journal for RuneScape: Dragonwilds.

## Download

[Download the latest installer](https://github.com/Shootinspide/DragonwildsCompanionRelease/releases/latest/download/Dragonwilds.Companion.Setup.exe),
[download the Android app](https://github.com/Shootinspide/DragonwildsCompanionRelease/releases/latest/download/Dragonwilds.Companion.Android.apk),
or open the **Releases** section to see release notes and the optional Windows
portable ZIP. Install the Windows companion first because it supplies the
phone with live game data over your private Wi-Fi.

## Updates

Installed copies verify a signed update manifest and the installer SHA-256
before offering an update. The private release-signing key is never stored in
this repository.

The mobile bridge is off by default. Pairing is single-use and time-limited,
and live traffic is authenticated and encrypted. Save files, Steam IDs,
Windows paths, account credentials and passwords are never sent to the phone.
